# OmniFetch Browser Scout (Chrome MV3 Extension)

This directory contains the Chrome Manifest V3 extension for OmniFetch.

## Architecture

1. **Interception**: Monitors `chrome.downloads.onDeterminingFilename`.
2. **Cancellation**: Calls `chrome.downloads.cancel()` before the native browser download writes to disk.
3. **Context Harvesting**: Extracts URL, Referrer, Domain Authentication Cookies via `chrome.cookies.getAll`, User-Agent, and suggested file name.
4. **IPC Dispatch**: Sends 32-bit length-prefixed JSON to `com.omnifetch.bridge` (OmniFetch Native AOT Bridge).

## Development Installation

1. Open Google Chrome and navigate to `chrome://extensions`.
2. Enable **Developer mode** (toggle in upper right).
3. Click **Load unpacked** and select this directory (`extension/`).
4. Note the Extension ID generated by Chrome and ensure it is registered in:
   `~/Library/Application Support/Google/Chrome/NativeMessagingHosts/com.omnifetch.bridge.json`
